# Website Promosi UMKM Kuliner

Website satu halaman berbasis HTML, CSS, dan JavaScript.

## Cara membuka
1. Ekstrak ZIP.
2. Buka folder `umkm-kuliner` di VS Code.
3. Buka `index.html` di browser (klik dua kali) atau gunakan ekstensi Live Server.

## Bagian yang bisa diedit
- `CONFIG`: nama usaha, nomor WhatsApp, alamat, dan jam buka.
- `MENU`: nama produk, kategori, deskripsi, harga, dan URL gambar.
- `#galeri`: ubah `src` serta `data-image` pada setiap kartu galeri untuk mengganti contoh foto.

## Catatan gambar dan data
Foto menu dan galeri saat ini memakai URL foto eksternal sebagai contoh. Koneksi internet diperlukan untuk memuat foto dan Google Fonts. Sebelum promosi, ganti foto contoh dengan foto produk asli, periksa harga, alamat, jam operasional, serta nomor WhatsApp. Harga dan identitas dalam template adalah data demo, bukan klaim fakta usaha.

Pesanan dibuka melalui WhatsApp. Website ini belum memiliki database, checkout otomatis, atau pembayaran online.
